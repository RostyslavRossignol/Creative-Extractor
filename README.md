# Creative Extractor

Готовый статический Next.js-проект для подготовки CSV массового импорта Meta Ads.

## Возможности

- загрузка оригинального Meta CSV в UTF-16/TAB или очищенного CSV;
- безопасная очистка проверенных технических колонок;
- массовая замена только в `Campaign Name`, `Ad Set Name` и `Ad Name`;
- сопоставление объявлений с JPG/PNG и видео из ZIP по языку и варианту;
- получение `Image Hash` через официальный Meta Graph API;
- ручной поиск и выбор любого креатива для каждой строки;
- миниатюры изображений и увеличенный предпросмотр при наведении;
- формирование готового CSV и пакета для импорта;
- локальная обработка файлов без загрузки на сторонний сервер.

## Локальный запуск

Требуется Node.js 22 LTS или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Полная проверка проекта:

```bash
npm run check
```

## Публикация на GitHub Pages

В проект уже включён workflow `.github/workflows/deploy-pages.yml`.

1. Поместите содержимое этой папки в корень репозитория.
2. Выполните `git add .`, commit и push в ветку `main`.
3. В `Settings → Pages` выберите `Source: GitHub Actions`.
4. Для собственного домена создайте Repository variable:

```text
CUSTOM_DOMAIN = creative-extractor.autostat.pp.ua
```

После push workflow соберёт статический сайт в `out` и опубликует его.

## Что не нужно загружать в Git

Папки `node_modules`, `.next` и `out` создаются автоматически и уже внесены в `.gitignore`.
В архиве их намеренно нет. Вложенных копий проекта и папки `.git` также нет.

## Безопасность токена

Токен хранится только в `sessionStorage` текущей вкладки: переживает обновление страницы,
но удаляется после закрытия вкладки или по кнопке удаления. Не публикуйте токен в коде,
`.env`, commit или скриншотах.
