# Creative Extractor

Готовый статический Next.js-проект для подготовки CSV массового импорта Meta Ads.

## Возможности

- загрузка оригинального Meta CSV в UTF-16/TAB или очищенного CSV;
- безопасная очистка проверенных технических колонок;
- автоматическое восстановление `Creative Type` вместо `POST_DELETED`, а при неоднозначности — очистка невалидного значения;
- массовая замена только в `Campaign Name`, `Ad Set Name` и `Ad Name`;
- сопоставление объявлений с JPG/PNG и видео из ZIP по языку и варианту: известные языки распознаются по названиям и кодам, а любой собственный языковой маркер — по одинаковому написанию в объявлении и имени файла без учёта регистра;
- два способа получения `Image Hash`: поиск уже загруженных изображений или прямая загрузка JPG/PNG из ZIP через официальный Meta Graph API;
- два отдельных блока видео: простая интеграция и автоинтеграция;
- получение всех доступных токену рекламных кабинетов с красной маркировкой недоступных;
- получение пикселей и доступных для продвижения Facebook Pages выбранного кабинета;
- редактирование `Countries`, `Locales`, пикселя и страницы в существующем CSV;
- ускоренная загрузка очередью до трёх одновременных запросов с прогрессом, результатом по каждому файлу и повтором только неудачных запросов;
- предварительная проверка доступа токена к кабинету до отправки файлов;
- извлечение правильного ID рекламного кабинета из параметра `act=` полной ссылки Ads Manager;
- ручной поиск и выбор любого креатива для каждой строки;
- миниатюры изображений и увеличенный предпросмотр при наведении;
- встроенная видеоинструкция с отложенной загрузкой, звуком и полноэкранным режимом;
- краткая пошаговая инструкция в верхнем меню и заметное напоминание о правильном профиле AdsPower;
- формирование готового CSV и пакета для импорта;
- локальная обработка файлов без загрузки на сторонний сервер.

## Локальный запуск

Требуется Node.js 22 LTS или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Полная проверка проекта:

```bash
npm run check
```

## Публикация на GitHub Pages

В проект уже включён workflow `.github/workflows/deploy-pages.yml`.

1. Поместите содержимое этой папки в корень репозитория.
2. Выполните `git add .`, commit и push в ветку `main`.
3. В `Settings → Pages` выберите `Source: GitHub Actions`.
4. Для собственного домена создайте Repository variable:

```text
CUSTOM_DOMAIN = creative-extractor.autostat.pp.ua
```

После push workflow соберёт статический сайт в `out` и опубликует его.

## Что не нужно загружать в Git

Папки `node_modules`, `.next` и `out` создаются автоматически и уже внесены в `.gitignore`.
В архиве их намеренно нет. Вложенных копий проекта и папки `.git` также нет.

## Безопасность токена

Токен хранится только в `sessionStorage` текущей вкладки: переживает обновление страницы,
но удаляется после закрытия вкладки или по кнопке удаления. Не публикуйте токен в коде,
`.env`, commit или скриншотах.

Для режима поиска достаточно `ads_read` или `ads_management`. Для прямой загрузки
изображений системному пользователю нужен `ads_management`, а выбранный рекламный
кабинет должен быть назначен ему с правом управления. Приложение отправляет файлы
непосредственно на `graph.facebook.com`; изображения и токен не проходят через
сторонний сервер.

## Полная последовательность работы

### 1. Откройте правильное окружение

Откройте Creative Extractor внутри того же браузерного профиля AdsPower и с того
же закреплённого IP/прокси, с которых вы входите в Ads Manager и выполняете залив
в нужный рекламный аккаунт (King).

### 2. Подготовьте исходные файлы

1. Выгрузите исходный CSV кампании из Meta Ads Manager.
2. Соберите JPG/PNG в ZIP без изменения исходных имён.
3. Убедитесь, что язык и номер варианта присутствуют и в `Ad Name`, и в имени
   файла. Регистр не учитывается: `Catalan` и `catalan` считаются совпадением.
4. Загрузите в сервис CSV и ZIP, затем проверьте сопоставление строк.

### 3. Настройте системного пользователя и токен

1. В Meta Business Settings откройте `Пользователи → Системные пользователи`.
2. Выберите системного пользователя, через которого работает Meta-приложение.
3. Через `Назначить ресурсы` добавьте нужный рекламный кабинет и выдайте право
   управления рекламными кампаниями/полный контроль.
4. Убедитесь, что Meta-приложение принадлежит или подключено к бизнес-портфелю и
   доступно выбранному системному пользователю.
5. Нажмите `Создать токен`, выберите приложение и срок `Never / Никогда`, если
   такой вариант доступен.
6. Выберите `ads_management` и `ads_read`. В используемой рабочей схеме также
   можно оставить `business_management`.
7. Скопируйте токен и вставьте его в поле `Access token` в Creative Extractor.
   Не отправляйте токен в чаты и не сохраняйте его в GitHub.

### 4. Укажите рекламный кабинет

Можно ввести числовой ID или вставить полную ссылку Ads Manager. Сервис извлечёт
только параметр `act=`. Параметры `business_id` и `global_scope_id` не являются
ID рекламного кабинета. Автоматически найденный по неймингу ID необходимо сверить
с `act=` в адресной строке Ads Manager.

### 5А. Старый режим «Найти в Meta»

1. Заранее загрузите JPG/PNG в нужный рекламный кабинет, сохранив имена файлов.
2. Добавьте CSV и ZIP в Creative Extractor.
3. Введите ID кабинета и токен с `ads_read` или `ads_management`.
4. Выберите `Найти в Meta` и нажмите `Найти креативы`.
5. Исправьте строки `Не найдено` или `Конфликт`.
6. После подтверждения всех изображений скачайте готовый CSV.

### 5Б. Новый режим «Загрузить в Meta»

1. Добавьте CSV и ZIP. Заранее загружать изображения в Meta не требуется.
2. Введите ID/ссылку кабинета и токен с `ads_management`.
3. Выберите `Загрузить в Meta` и запустите загрузку изображений.
4. Сервис проверит доступ токена к кабинету, затем загрузит JPG/PNG очередью не
   более трёх одновременных запросов. `Image Hash` возвращается непосредственно
   в ответе Meta на загрузку каждого изображения — отдельный запрос не выполняется.
5. При единичных сбоях исправьте причину и нажмите `Повторить ошибки`.
6. После статуса `Все изображения загружены` скачайте готовый CSV.

### 6. Импортируйте готовый CSV

1. В Ads Manager откройте импорт объявлений и выберите готовый CSV.
2. В Preview проверьте названия, изображения и отсутствие `Image Not Found`.
3. Сначала сохраните кампании в черновик и только после ручной проверки публикуйте.

Автоматическая API-загрузка в текущей версии поддерживает JPG и PNG. Видео MP4/MOV
этим режимом не загружаются.

Автоматический режим использует официальный Meta Graph API, но это не является
гарантией отсутствия автоматических проверок или ограничений со стороны Meta.
Сохраняйте простой режим как резервный, сначала импортируйте кампании в черновик
и проверяйте результат вручную.

## Возможности версии 1.8.0

После ввода токена можно получить рекламные кабинеты через `/me/adaccounts`,
а для выбранного кабинета — пиксели через `/adspixels` и доступные для продвижения
страницы через `/promote_pages`. Дополнительно страницы ищутся через `/me/accounts`,
`/owned_pages` и `/client_pages`. Активные кабинеты отображаются зелёными,
а заблокированные и недоступные — красными и остаются видимыми для диагностики.

Редактор меняет только существующие колонки экспорта Meta: `Countries`, `Locales`,
`Optimized Conversion Tracking Pixels`, `Conversion Tracking Pixels` и
`Link Object ID`. Это подготовка импортируемого CSV, а не прямая публикация
кампании через API. Перед публикацией изменения необходимо проверить в Preview.

## Рабочее окружение

Открывайте сервис внутри того же браузерного профиля в приложении AdsPower и
с того же закреплённого IP/прокси, с которых вы входите в Ads Manager и выполняете
залив в нужный рекламный аккаунт (King). Профиль AdsPower и его IP должны
соответствовать именно тому аккаунту, с которого выполняется залив.
